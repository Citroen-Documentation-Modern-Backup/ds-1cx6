D4EH0DP0Procédures d’apprentissage et de programmation : Boîtier de servitude intelligent (BSI) - Calculateur de contrôle moteur
1. Outillage de diagnostic
Station "LEXIA" : 4171-T.
Station "PROXIA" : 4165-T.
Station "LEXIA 3".
Station "PROXIA 3".
ATTENTION : Les BSI, les calculateurs de contrôle moteur et les clés sont affectés à un véhicule et ne peuvent donc pas être échangés entre deux véhicules.
IMPERATIF : Le code confidentiel véhicule est nécessaire pour toutes ces opérations.
2. Initialisation d’un boîtier de servitude intelligent
NOTA : Cette procédure d’initialisation intègre de façon automatique l’apprentissage des clés du véhicule et le choix du plan de maintenance (préparation du véhicule neuf).
2.1. Conditions préalables
IMPERATIF : Ne pas démarrer le moteur avant la fin de l’initialisation du BSI.
Avant de démarrer le moteur :
  • Placer le levier de vitesses en position parking "P"
  • Activer le frein de stationnement à commande électrique
2.2. Procédure d’initialisation avec l’outil de diagnostic " LEXIA" ou "PROXIA"
Connecter l’outil de diagnostic à la prise diagnostic du véhicule.
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "apprentissage"
  • "INITIALISATION BSI"
Suivre les instructions données par l’outil de diagnostic.
Au cours de la procédure d’initialisation du boîtier de servitude intelligent, il est demandé d’effectuer les opérations suivantes :
  • Écriture du code confidentiel client dans le boîtier de servitude intelligent
  • Apprentissage des clés
  • Synchronisation des télécommandes haute fréquence (voir opération correspondante)
  • Choix du plan de maintenance
La procédure d’apprentissage terminée, effectuer les opérations suivantes :
  • Réinstaller, si nécessaire, les accessoires ajoutés au véhicule
  • Effectuer l’appairage du calculateur de contrôle moteur avec le boîtier de servitude intelligent
3. Programmation d’un calculateur de contrôle moteur
NOTA : Cette procédure d’apprentissage est valable pour les outils de diagnostic LEXIA et PROXIA.
Connecter l’outil de diagnostic à la prise diagnostic du véhicule.
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "INJECTION" (outil de diagnostic LEXIA) ou "MOTOPROPULSEUR" (outil de diagnostic PROXIA)
  • "PROGRAMMATION/APPAIRAGE"
Suivre les instructions données par l’outil de diagnostic.
Effectuer l’appairage du calculateur de contrôle moteur avec le boîtier de servitude intelligent.
4. Appairage avec le boîtier de servitude intelligent
NOTA : Cette procédure d’appairage est valable pour les outils de diagnostic LEXIA et PROXIA.
Pour le menu "appairage", suivre la procédure de programmation d’un calculateur de contrôle moteur.
Répondre :
  • "NON", pour entrer un nouveau code confidentiel
  • "OUI", pour effectuer un appairage avec le BSI
Suivre les instructions données par l’outil de diagnostic.
