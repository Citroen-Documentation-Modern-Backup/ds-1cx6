C5FG1KP0Dépose - repose : Console centrale
1. Opération préliminaire
Déposer la façade centrale de planche de bord (voir opération correspondante).
2. Dépose
Déclipper le pommeau de levier de vitesses.
Figure : c5fp0sac
Déclipper :
  • La grille de sélection de vitesses ( 3)
  • Les commandes (1)
  • L’enjoliveur (2)
  • L’enjoliveur (4) (déconnecter l’allume-cigares)
  • Le vide-poches (5)
Déconnecter la commande de frein de stationnement électrique ( 6).
Figure : c5fp0sbc
Déposer les vis en " a".
Figure : c5fp0scc
Déclipper l’aérateur ( 8).
Déconnecter le bouton de commande de climatisation ( 7).
Figure : c5fp0sdc
Déposer les vis (9).
Déclipper la finition arrière de la console ( 10).
Déconnecter les allume-cigares.
Figure : c5fp0sed
Déposer la garniture de fond de vide-poches ( 12).
Déclipper :
  • La prise de diagnostic ( 11)
  • La commande de secours du frein de stationnement électrique (13)
Déposer :
  • Les vis en " b"
  • La console centrale
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Figure : c5fp0sfc
ATTENTION : Clipper la commande de secours du frein de stationnement électrique ( 13).
