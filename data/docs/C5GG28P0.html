2. Opérations préliminaires
Déposer :
  • Les garnitures de montant de baie
  • Les garnitures de pieds milieu
  • Les garnitures de custode
  • Troisième feu de stop
3. Dépose
3.1. Pare-soleil
Figure : c5gg0tfd
Déposer (de chaque côté) :
  • Les vis (4) et (1)
  • Le support (2)
Dégager l’ergot  (en "b").
Déconnecter le connecteur  (en "a").
Déposer le pare-soleil (3).
3.2. Poignée de maintien
Figure : c5gg0tgd
Abaisser la poignée de maintien (7).
Déclipper les caches articulés (5).
Déposer :
  • Les vis (6)
  • La poignée de maintien (7)
NOTA : Effectuer les opérations identiques pour les autres poignées de maintien (7).
3.3. Console de plafonnier
Figure : c5gg0thd
Déclipper le cache (8) ; À l’aide de l’outil [1350-ZZ].
Figure : c5gg0tid

Figure : c5gp0ftd
Déposer les vis (9).
Figure : c5gg0tld
Déclipper les rotules  (en "d") ; À l’aide de l’outil [1350-ZZ].
Déconnecter les connecteurs  (en "e").
Déclipper les capteurs d’alarme (10).
Déposer la console plafonnier (11).
3.4. Plafonnier arrière
Figure : c5gg0tod
Déclipper les verrouillages  (en "f") ; À l’aide de l’outil [1350-ZZ].
Dégager la partie avant du plafonnier arrière (suivant flèche ).
Figure : c5gg0tqd
Déposer les ergots "g" de la garniture de pavillon.
Déverrouiller et déconnecter le connecteur "" (en "h").
Déposer le plafonnier arrière (12).
3.5. Garniture de pavillon
Figure : c5gg0ttd
Déposer :
  • Le siège avant droit
  • La porte avant droite
NOTA : Lors de la découpe des cordons de colle, ne pas entailler la garniture de pavillon (13).
Sortir la garniture de pavillon (13) par la porte avant droite.
4. À l’établi
Araser les cordons d’adhésif joint polyuréthane restant sur le pavillon.
Figure : c5gg0tvd
"j" : Cordon d’adhésif joint polyuréthane.
Vérifier la présence des éléments suivants :
  • Faisceau de plafonnier arrière (14)
  • Mousses de calage (15) et (16)
Appliquer les cordons d’adhésif joint polyuréthane en "j" : À l’aide d’un pistolet applicateur .
5. Repose
Poser : La garniture de pavillon (13) (faire coïncider les différentes ouvertures).
Effectuer la suite des opérations dans le sens inverse des opérations de dépose.
6. Opérations complémentaires
Reposer :
  • Troisième feu de stop
  • Les garnitures de custode
  • Les garnitures de pieds milieu
  • Les garnitures de montant de baie
