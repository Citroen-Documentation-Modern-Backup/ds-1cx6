B1IG05P0Dépose - repose : Bougies d’allumage
IMPERATIF : Respecter les consignes de sécurité et de propreté.
ATTENTION : Avant de débrancher la batterie, entrebâiller les vitres des portes.
1. Dépose
1.1. Bougies d’allumage (rangée de cylindres avant)
Débrancher la batterie .
Déposer le cache-style .
Figure : b1bp292d
Déconnecter :
  • Le faisceau moteur (1)
  • Les connecteurs (3)
Déposer les vis (2).
Figure : b1bp293d
Déposer :
  • Les bobines d’allumage (4)
  • Les bougies d’allumage (5)
1.2. Bougies d’allumage (rangée de cylindres arrière)
Déposer le collecteur d’admission (voir opération correspondante).
Figure : b1bp294d
Déconnecter les connecteurs (6).
Déposer :
  • Les vis (7)
  • Les bobines d’allumage
  • Les bougies d’allumage (/)
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Couple de serrage :
  • Bougies d’allumage : 2,8 ± 0,3 m.daN
  • Bobines d’allumage : 0,8 ± 0,2 m.daN
IMPERATIF : Réaliser les opérations à effectuer après un rebranchement de la batterie (voir opération correspondante).
