D4EM4LP0Procédure de "télécodage" : Boîtier de servitude intelligent (BSI)
1. Observations
Une lecture des paramètres télécodables, avec l’outil de diagnostic, ne nécessite pas de disposer du code d’accès véhicule inscrit sur la carte confidentielle client.
Le code d’accès Après Vente est indispensable pour effectuer les modifications suivantes :
  • Paramètres de configuration
  • Liste des calculateurs
  • Code VIN
2. Outillage de diagnostic
Station "LEXIA : 4171-T".
Station "PROXIA : 4165-T".
Station "LEXIA 3".
Station "PROXIA 3".
3. Procédure de "télécodage" (outil de diagnostic "LEXIA" ou "PROXIA")
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "TÉLÉCODAGE"
  • "TÉLÉCODAGE MANUEL"
Choisir l’un des sous-menus suivants :
  • "OPTIONS CLIENT" (voir nota)
  • "CONFIGURATION" (voir nota)
  • "CALCULATEURS PRÉSENTS"
  • "CODE VIN"
NOTA : Options client : Dans ce menu se trouvent toutes les options disponibles pour le client en fonction des spécificités du véhicule.
Le sous-menu "CONFIGURATION" se compose de 5 sous-menus :
  • "DÉFINITION DU VÉHICULE - ÉQUIPEMENTS - INFORMATIONS CONDUITE"
  • "CLIMATISATION - CHAUFFAGE DE L’HABITACLE"
  • "ÉCLAIRAGE - SIGNALISATION - VISIBILITÉ - RÉTROVISEURS"
  • "VERROUILLAGE - OUVRANTS - ANTIDÉMARRAGE - ALARME"
  • "LOI DE JAUGE CARBURANT - LOI DE JAUGE NIVEAU D’HUILE"
4. Procédure de "choix du plan de maintenance" (outil de diagnostic "LEXIA" ou "PROXIA") (préparation du véhicule neuf)
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "MAINTENANCE" - "MODE DE FONCTIONNEMENT DU BSI"
  • "MAINTENANCE"
  • "CHOIX DU PLAN DE MAINTENANCE" (préparation du véhicule neuf)
5. Procédure de passage du véhicule en "MODE SHOW ROOM" (outil de diagnostic "LEXIA" ou "PROXIA")
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "MAINTENANCE" - "MODE DE FONCTIONNEMENT DU BSI"
  • "MODE DE FONCTIONNEMENT DU BSI"
  • "MODE SHOW ROOM"
IMPERATIF : Le paramètre "MODE SHOW ROOM" ne doit être validé que pour les véhicules d’exposition.
6. Procédure de passage du véhicule en "MODE CLIENT" (outil de diagnostic "LEXIA" ou "PROXIA")
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule
  • "TEST GLOBAL"
  • "CALCULATEUR BSI"
  • "MAINTENANCE" - "MODE DE FONCTIONNEMENT DU BSI"
  • "MODE DE FONCTIONNEMENT DU BSI"
  • "MODE CLIENT"
NOTA : Le mode client permet de sortir le véhicule des modes "show-room", parc ou usine.
