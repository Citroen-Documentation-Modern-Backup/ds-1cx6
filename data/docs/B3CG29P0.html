B3CG29P0Dépose - repose : Articulations élastiques de support de pivot avant
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap2nld
[ 1] Tampon de dépose articulation élastique supérieur de support de pivot avant (-).0548.E.
[2] cloche de dépose (-).0548.A3.
[ 3] vis guide (-).0548.A1 + rondelle M10 (-).0548.A2.
Figure : e5ap2nzd
[ 4] Bague de repose (-).0548.F3.
[ 5] vis guide (-).0548.F1 + rondelle M12 (-).0548.F2 + écrou HM12 (-).0548.F4.
2. Dépose
Déposer l’élément porteur avant (voir opération correspondante).
Figure : b3cp09zd
Déposer :
  • La vis (1)
  • Le support de pivot avant (2)
Immobiliser le support de pivot avant ( 2) dans un étau équipé de mordaches.
Figure : b3cp0a0d
X = 10 mm .
Effectuer un repère " a" sur chaque articulation élastique à la cote X.
Figure : b3cp0a1d
ATTENTION : Aucun trait de scie ne doit apparaître sur le support de pivot avant.
Scier les articulations élastiques suivant les repères " a".
Figure : b3cp0a2d
Poser les outils [ 1], [2] et [3] sur l’articulation élastique.
Extraire l’articulation élastique À l’aide de l’outil [3].
NOTA : Répéter l’opération sur l’articulation élastique opposée.
3. Repose
Figure : b3cp0a3d
Poser :
  • Les articulations élastiques
  • Les outils [ 4] et [5]
Serrer l’outil [ 5] jusqu’à la mise en place des articulations élastiques.
ATTENTION : Le montage de l’articulation élastique doit se faire avec un effort à l’emmanchement . Lorsque l’articulation élastique se monte librement, procéder au remplacement du support de pivot avant.
Reposer :
  • Le support de pivot avant ( 2)
  • La vis (1)
  • L’élément porteur avant (voir opération correspondante)
Serrer la vis ( 1) à l’assiette de serrage : 8,5 ± 0,8 m.daN.
