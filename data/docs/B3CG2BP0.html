B3CG2BP0Dépose - repose : Berceau avant  (moteur ES9)
IMPERATIF : Respecter les consignes de sécurité et de propreté .
ATTENTION : Avant de débrancher la batterie, entrebâiller les vitres des portes.
1. Contrôle : Cadre de berceau avant
Figure : b3cp0avd
A = 4 mm.
Contrôler le jeu " A" entre les butoirs (1) et le cadre de berceau avant.
NOTA : Si le jeu est inférieur à la cote " A", remplacer le cadre de berceau avant.
2. Dépose
Lever et caler le véhicule sur un pont à 2 colonnes.
IMPERATIF : Se reporter aux directives de l’opération "mise hors pression des circuits de suspension".
Débrancher la batterie .
Déposer :
  • Les roues avant
  • Les parties avant des pare-boue avant
  • L’insonorisant sous moteur
2.1. Cadre de berceau avant
Figure : b3cp0awd
Déposer les vis (2).
Écarter les canalisations de direction assistée de l’allonge de berceau avant.
Figure : b3cp0axd
Déposer vis (3)  (de chaque côté).
Figure : b3cp0ayd
Déposer  (de chaque côté) :
  • La vis (4)
  • Les écrous (5)
Écarter et suspendre l’ensemble support / capteur de débattement de roue.
IMPERATIF : Toutes déformations du support de capteur de débattement de roue nécessite son remplacement.
Figure : b3cp0azd
Déposer  (de chaque côté) :
  • Les fixations (6)
  • Le cadre de berceau avant
2.2. Berceau avant
Figure : b1jp096d
Déposer la ligne d’échappement .
Figure : b3cp0b0d
Déposer  (de chaque côté) :
  • L’écrou (7)
  • La fixation (8)
Désaccoupler les biellettes de barre antidévers avant.
Figure : b3cp0b1d
Déconnecter le connecteur "a".
Dégrafer le faisceau du connecteur du berceau avant.
Figure : b3cp0b2d
Déposer :
  • La vis (9)
  • Les écrous (10)
  • Les goujons (11)
  • Les cales du mécanisme de direction
Suspendre le mécanisme de direction à la structure du véhicule.
Positionner un outil de levage sous le berceau avant.
Figure : b3cp0b3d
Déposer :
  • Les vis (12)
  • Les vis (14)
  • Les chapes ( 13)
Écarter le berceau avant de la caisse de quelques centimètres.
Déposer le berceau avant.
3. Repose
IMPERATIF : Remplacer systématiquement les écrous Nylstop.
3.1. Berceau avant
Positionner le berceau avant sur le véhicule à quelques centimètres de la caisse.
Engager les goujons ( 11) de fixation du mécanisme de direction avec les cales de mécanisme de direction sur le berceau avant.
Positionner le berceau avant sur la caisse.
Reposer :
  • Les chapes ( 13)
  • Les vis (14) : Serrer à 14 m.daN
  • Les vis (12) : Serrer à 10 m.daN
Serrer les goujons (11) à 0,9 m.daN.
Reposer :
  • Les écrous (10) : Serrer à 14,9 m.daN
  • La vis (9) : Serrer à 6,5 m.daN
Connecter le connecteur en " a".
Agrafer le faisceau du connecteur sur le berceau avant.
Accoupler les biellettes de barre antidévers avant.
Reposer  (de chaque côté) :
  • L’écrou (7)  (sans serrer)
  • La fixation (8)  (sans serrer)
Figure : b3bp1apd
X = 58 ± 5 mm.
Positionner le bras inférieur de suspension avant à la cote X.
Serrer  (de chaque côté) :
  • L’écrou (7) à 5 m.daN
  • La fixation ( 8) à 7,5 m.daN
Reposer la ligne d’échappement.
3.2. Cadre de berceau avant
Positionner le cadre de berceau avant.
Reposer :
  • Les fixations (6)  (sans serrer)
  • Les vis (3)  (sans serrer)
Contrôler le positionnement du cadre de berceau avant  (cote " A").
Couples de serrage :
  • Serrer les fixations ( 6) à 6,5 m.daN
  • Serrer les vis (3) à 6,5 m.daN
IMPERATIF : Toutes déformations du support de capteur de débattement de roue nécessite son remplacement.
Reposer  (de chaque côté) :
  • L’ensemble support / capteur de débattement de roue
  • La vis (4) : Serrer à 0,8 m.daN
  • Les écrous (5) : Serrer à 0,8 m.daN
Positionner les canalisations de direction assistée sur l’allonge de berceau avant.
Reposer les vis (2).
Reposer :
  • L’insonorisant sous moteur
  • Les parties avant des pare-boue avant
  • Les roues avant
Rebrancher la batterie.
IMPERATIF : Réaliser les opérations à effectuer après un rebranchement de la batterie  (voir opération correspondante).
Contrôler les hauteurs véhicule  (voir opération correspondante).
Effectuer l’apprentissage des capteurs de débattement de roue si nécessaire  (voir opération correspondante).
Contrôler et régler le parallélisme.
