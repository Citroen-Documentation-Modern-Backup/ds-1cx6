C5BS01P0Déshabillage - habillage : Couvercle de coffre
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Déshabillage
Figure : c4ap1jdd
Déposer :
  • La garniture (1)
  • Le déflecteur mobile de coffre (voir opération correspondante)
Figure : c4bp1hrd
Déposer :
  • Les vis (6)
  • La serrure (5)
Déconnecter le connecteur de la serrure .
Déposer :
  • Les vis (4)
  • Le support de plaque d’immatriculation (3)
Déconnecter le connecteur du support de plaque d’immatriculation.
Déposer le faisceau électrique (2).
Figure : c5ep031d
Déconnecter les connecteurs en " a".
Déposer le faisceau électrique (10).
Déclipper :
  • Les éclairages de plaque d’immatriculation ( 8)
  • Le contacteur de commande d’ouverture de couvercle de coffre (9)
Déposer :
  • Les vis (7)
  • Les feux arrière (11)
Déposer la plaque d’immatriculation , Percer les têtes de rivets à l’aide d’un foret Ø 5 mm.
2. Habillage
Poser :
  • La plaque d’immatriculation (voir opération correspondante)
  • Les feux arrière (11)
  • Les vis (7)
Clipper :
  • Les éclairages de plaque d’immatriculation ( 8)
  • Le contacteur de commande d’ouverture de couvercle de coffre (9)
Poser le faisceau électrique ( 10).
Connecter les connecteurs en " a".
Poser le faisceau électrique ( 2).
Connecter le connecteur du support de plaque d’immatriculation.
Poser :
  • Le support de plaque d’immatriculation ( 3)
  • Les vis (4)
Connecter le connecteur de la serrure.
Poser :
  • La serrure (5)
  • Les vis (6)
  • Le déflecteur mobile de coffre (voir opération correspondante)
  • La garniture (1)
