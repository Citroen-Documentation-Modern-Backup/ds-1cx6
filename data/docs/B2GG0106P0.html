B2GG0106P0Dépose - Repose : Éléments de détection de sous-gonflage
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Calculateur de détection de sous-gonflage
ATTENTION : Un apprentissage est nécessaire en cas d’échange de l’élément, se reporter à la documentation outils de diagnostic. Un forceur est utilisé conjointement avec l’outil de diagnostic pour l’apprentissage.
1.1. Dépose
Déposer la tablette arrière .
Figure : c4cg0gbd
Déconnecter le connecteur ( en "a").
Dégrafer et déposer Le calculateur (1).
1.2. Repose
Agrafer Le calculateur (1).
Connecter le connecteur ( en "a").
Reposer la tablette arrière .
2. Antennes basses fréquences
2.1. Dépose
Lever et caler le véhicule, roues avant pendantes.
Déposer les roues avant.
Dégager partiellement les pare-boue avant (En partie arrière).
Figure : c4cg0g9d
Déconnecter les connecteurs ( en "b").
Déposer de chaque côté :
  • Les écrous (2)
  • L’antenne basses fréquences (3)
2.2. Repose
ATTENTION : Respecter les couples de serrage .
Reposer de chaque côté :
  • L’antenne basses fréquences (3)
  • Les écrous (2)
Connecter les connecteurs ( en "b").
Reposer :
  • Les pare-boue avant (En partie arrière )
  • Les roues avant
  • Le véhicule sur ses roues
Serrer les vis de roues .
