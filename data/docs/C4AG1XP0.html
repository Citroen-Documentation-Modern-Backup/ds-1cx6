C4AG1XP0Dépose - repose : Capot moteur
1. Dépose
NOTA : Pour l’opération de dépose 2 opérateurs sont nécessaires.
Figure : c4ap1j3d
Désaccoupler le tuyau de lave-vitres en "b".
Percer les rivets (5) à l’aide d’un foret Ø 5 mm.
Déposer :
  • La bride de maintien (6)
  • Les pions (4) (de chaque côté)
  • Les enjoliveurs (3) (de chaque côté)
  • Les stabilisateurs (de chaque côté)
  • Les vis (2) en "a"
  • Le capot moteur (1)
2. Déshabillage
Figure : c4ap1jgd
Déposer :
  • Les gicleurs de lave-vitre
  • Les butées caoutchouc (7), (9)
  • Les agrafes (10)
  • La garniture de capot (11)
  • Les agrafes (8)
  • L’enjoliveur de capot
3. Repose
Reposer :
  • Le capot moteur (1)
  • Les vis (2) en "a"
  • Les stabilisateurs
  • Les enjoliveurs (3)
  • Les pions (4)
Riveter la bride de maintien (6).
ATTENTION : Respecter les jeux et affleurements.
4. Habillage
4.1. Habillage du capot
Reposer :
  • L’enjoliveur de capot
  • Les agrafes (10)
  • La garniture de capot (11)
  • Les agrafes (8)
  • Les butées caoutchouc (7), (9)
  • Les gicleurs de lave-vitre
4.2. Pose de l’enjoliveur de capot
Nettoyer la zone d’application à l’aide d’un produit (J1).
Chauffer la zone d’application à 20°C.
Enlever le papier protecteur de l’enjoliveur de capot.
Présenter les tétons de l’enjoliveur de capot en face des perçages de positionnement.
Appliquer l’enjoliveur de capot.
Appuyer fortement à l’aide d’un chiffon propre sur l’enjoliveur de capot (5 secondes minimum) du milieu vers les extrémités.
Poser les agrafes (8) des extrémités vers le milieu de l’enjoliveur de capot.
